WartaSehat.id

WartaSehat.id adalah aplikasi web sistem informasi pelayanan klinik dan pencatatan rekam medis elektronik (Electronic Medical Record). Aplikasi ini dirancang untuk membantu digitalisasi alur administrasi pasien serta menghubungkan proses kerja antara petugas pendaftaran dan dokter dalam satu sistem yang terintegrasi.

Fitur Utama

Autentikasi & Hak Akses Pengguna: Sistem login dan manajemen sesi yang memisahkan hak akses serta tampilan kerja berdasarkan peran pengguna (Petugas Administrasi dan Dokter).

Modul Petugas Administrasi:

Dashboard ringkasan aktivitas pelayanan.

Pendaftaran pasien baru dan pengelolaan daftar pasien.

Pengelolaan detail informasi pasien dan pemantauan riwayat rekam medis.

Modul Dokter:

Dashboard dokter dan pemantauan antrean poli secara langsung.

Penginputan hasil detail pemeriksaan medis pasien.

Penelusuran riwayat rekam medis pasien secara cepat.

Teknologi yang Digunakan

Frontend: HTML5, CSS3 (Modular & Responsif)

Backend: PHP (Native)

Database: MySQL / MariaDB

Cara Menjalankan di Lokal

Pastikan server lokal seperti XAMPP atau Laragon (Apache & MySQL) sudah aktif.

Salin folder proyek ini ke dalam direktori htdocs (untuk XAMPP) atau www (untuk Laragon).

Buka phpMyAdmin, buat database baru, lalu import file backend/database.sql.

Sesuaikan pengaturan koneksi database (nama database, username, dan password) pada file backend/koneksi.php.

Buka browser dan akses melalui alamat http://localhost/Projek Akhir/ (sesuaikan dengan nama folder proyek di lokal).
